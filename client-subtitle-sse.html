📖 使用说明

Unidirectional Server-Sent Events (SSE)

  • 原理: 使用浏览器原生 EventSource API 建立单向 SSE 连接
  • 优点:
    • 简单易用，浏览器原生支持
    • 自动重连
    • HTTP/1.1 兼容性好
    • 适合单向推送场景（字幕只需要服务端推送）
  • 连接方式: 通过 URL 参数传递 station_code，服务端通过 connect proxy 处理
  • 订阅机制: 服务端在 connect proxy 响应中返回要订阅的频道列表

与 WebSocket 模式对比

特性 SSE (uni_sse) WebSocket (bidirectional)
通信方向 单向（服务端→客户端） 双向
协议 HTTP/1.1 WebSocket
浏览器 API EventSource (原生) WebSocket (原生)
自动重连 ✅ 内置 ❌ 需手动实现
订阅方式 连接时指定（静态） 连接后动态订阅
适用场景 单向推送，频道固定 双向通信，动态订阅
